# 🏏 ODI Match Toss & Win Analysis Dashboard

This project is a **Streamlit dashboard** that provides visual insights into One Day International (ODI) cricket matches, focusing on the relationship between **toss decisions** and **match outcomes**.

## 📊 Features

- **Toss Wins by Each Team:** Bar chart showing how many times each team has won the toss.
- **Teams Winning Toss & Match:** Teams that won both the toss and the match.
- **Teams Winning After Losing Toss:** Analysis of matches where the toss-losing team still managed to win.
- **Winning Percentage by Country:** Pie chart of overall match-winning percentage for each team.
- **Toss Decision Analysis:** Visualization of whether teams chose to bat or field after winning the toss.
- **Matches per Venue:** Count plot showing distribution of matches across various venues.

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Pandas**
- **Plotly**
- **Matplotlib**
- **Seaborn**

## 📁 Dataset

The project uses a dataset named `ODI_Match_info.csv` containing match-level information such as:
- `toss_winner`
- `winner`
- `team1`, `team2`
- `toss_decision`
- `venue`

> ⚠️ Make sure this CSV file is available in the root directory of your project.
